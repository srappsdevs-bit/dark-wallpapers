## 🚀 How to Use in Your App

### 1. Complete JSON Manifest
Your app can fetch all wallpapers with direct URLs in one request:
```
https://raw.githubusercontent.com/srappsdevs-bit/dark-wallpapers/main/wallpapers.json
```
or via fast CDN:
```
https://cdn.jsdelivr.net/gh/srappsdevs-bit/dark-wallpapers@main/wallpapers.json
```

### 2. Direct Image URLs
- **Raw GitHub:** `https://raw.githubusercontent.com/srappsdevs-bit/dark-wallpapers/main/<folder>/<filename>`
